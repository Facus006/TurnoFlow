# TurnoFlow

Sistema de gestión de turnos desarrollado con Java y Spring Boot.

## Tecnologías
- Java
- Spring Boot
- Spring Security
- JWT
- MySQL
- Hibernate/JPA
- Docker
- Maven

## Funcionalidades
- Registro/Login
- Roles (ADMIN / CLIENTE / NEGOCIO)
- Reserva de turnos
- Confirmación/Rechazo/Cancelación
- Paginación
- Seguridad con JWT
