# TurnoFlow

API REST que permite a negocios gestionar sus turnos y a clientes reservarlos, con autenticación JWT y control de acceso por roles.

## Tecnologías
- Java
- Spring Boot
- Spring Security
- JWT
- MySQL
- Hibernate/JPA
- Docker
- Maven
- Swagger
- 
## Funcionalidades
- Registro/Login
- Roles (ADMIN / CLIENTE / NEGOCIO)
- Reserva de turnos
- Confirmación/Rechazo/Cancelación
- Paginación
- Seguridad con JWT
